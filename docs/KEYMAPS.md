# Keymaps

## Zsh

- `Esc` switches to normal mode (`bindkey -v`)
- `Ctrl-r` starts incremental history search

## Neovim

- Terminal mode: `<Esc>` -> terminal normal mode
- `<leader>gg` -> `LazyGit`
- `<leader>-` -> open yazi
- `<leader>ha` -> add current file to Harpoon
- `<leader>hh` -> toggle Harpoon quick menu
- `<leader>h1..h4` -> jump to Harpoon files 1-4
- `<leader>uT` -> toggle UndoTree

## Tmux

- Prefix: `Ctrl-Space`
- Pane movement: `h j k l`
- Split vertically: `Prefix + "`
- Split horizontally: `Prefix + %`
- New window in cwd: `Prefix + c`
- Install TPM plugins: `Prefix + Shift-I`
- Copy mode vi selection: `v` then `y`
- `Prefix + Ctrl-f` -> tmux-fzf switcher (session/window/pane)
